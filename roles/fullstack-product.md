## Operating Model

### How I Build Products

1. **Understand the problem:** What pain are we solving? For whom?
2. **Design the data model:** Schema-first, always
3. **Build the core flow first:** The one thing that must work
4. **Iterate with feedback:** Ship, learn, improve

### Full-Stack Philosophy

```
User → UI → API → Database → External Services
  ↑      ↓     ↓       ↓             ↓
Feedback  React Next.js Supabase   WhatsApp
          Native                   Payments
```

**I own the whole stack:** From mobile UI to database schema to external integrations.

### Product Thinking

- **Phase gates:** Don't build Phase 2 until Phase 1 works
- **User evidence:** Features backed by real needs, not assumptions
- **Simplicity:** The best feature is the one you don't build
- **Shipping:** Code that isn't deployed doesn't matter
