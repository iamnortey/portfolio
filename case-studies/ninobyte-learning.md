# Ninobyte Learning: make one useful AI workflow

**Status:** public learning site and free starter published inside Ninobyte School (account required); the larger Modern Leverage curriculum is still being developed.

[Learning website](https://learn.ninobyte.com/) · [Portfolio](../README.md)

## The problem

Trying an AI tool is different from knowing how to use its output in everyday work. A useful learning experience needs a clear task, a worked example and a way to catch errors.

## What I built

I built the public Ninobyte Learning website and prepared a school experience with practical resources and exercises. The free five-lesson starter, **Your first useful AI workflow**, uses a fictional meeting task. Learners provide context, inspect an intentionally flawed result, correct it and save a reusable instruction and check log.

The starter’s November publication checks covered learner enrollment, lesson progression and a downloadable worksheet. This is self-assessed practice, not accreditation or proof of learner outcomes.

**Modern Leverage** extends the approach into a seven-session programme. Its first session was published for invited review; the rest remains in development. A prepared curriculum is not a completed cohort.

## Adapting it for Greater Boston businesses

My proposed small-business training starts with work the owner already does: reviewing a stock export, drafting a customer reply, preparing a procedure or building a simple tool with Codex. Each session ends with an output to check and instructions the person can use again.

I bring the same approach to IT training: understand the system, practice with safe examples, test the result and document recovery. Training availability and scope would be agreed with each business.

**My role:** learning design, examples and worksheets, website implementation, review and learner-journey verification, with Codex and Claude Code supporting the build.
