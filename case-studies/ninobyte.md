I work solo with Codex and Claude Code to build useful software, test it and document how to run it. My work spans education, commerce, learning systems and business operations.

I help small businesses and teams develop their own capabilities: useful Codex setups, reusable agent skills, MCP servers, connectors, plugins and API workflows. The starting point is a task people understand and a result they can check.

## From project experience to practical training

The same patterns appear across different work: intake and recovery, finding reliable information, producing a useful document, connecting systems and teaching someone to repeat the process.

Training can apply those patterns to a business’s own tools, from spreadsheets and customer requests to inventory, printing workflows and internal applications. The [Clover/POS inventory pilot](../proposals/clover-inventory-pilot.md) is one proposed example.
