# Software and practical AI, built by one person

I’m **Isaac Nortey**, the person behind **Ninobyte**. I build with Codex and Claude Code, combining software development with practical AI and IT training.

My focus is **US small and micro businesses, starting in Greater Boston**: useful tools, clearer workflows and skills the owner can keep using.

[Ninobyte](https://ninobyte.com/) · [Learning](https://learn.ninobyte.com/) · [Contact Isaac](https://linkedin.com/in/inortey/)

## Builders 60

**Live application service · Two-builder initiative**

A programme needs more than a landing page. I built an application workflow with input checks, reliable retries, receipt recovery and separate consent choices, then verified it in real browsers.

The next learning direction is helping two builders use **Codex** to define, build, test and hand off a useful project.

## Proposed: a useful inventory workflow

For a Greater Boston retailer, I would start with an owner-approved stock export and one question worth answering. Build a small report, check it against the records, then teach the owner to run it.

If useful, the next step would be a merchant-authorized, read-only **Clover/POS connection to ChatGPT**, built with help from **Codex**. This is a proposed pilot.

[Read the pilot plan](./proposals/clover-inventory-pilot.md)

## How I work

I define the problem and own the decisions. Codex supports the build and iteration; Claude Code adds complementary engineering and review. I test realistic failures, check the user experience and document the handoff.

For a small business, the result should be understandable and repeatable. For a learner, it should be something they can explain and use again.
