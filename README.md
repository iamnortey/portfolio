# Software, connected tools and practical training

I’m **Isaac Nortey**, the person behind **Ninobyte**. I work solo, using **Codex** and **Claude Code** across development, testing and review.

I build useful software and help people develop the skills to use it, adapt it and make something of their own.

**[Visit Ninobyte](https://ninobyte.com/)** · [IT training](https://ninobyte.com/training) · [Discuss a project](https://ninobyte.com/contact)

## Training around real work

I help small businesses and teams build practical skills with their own tasks and tools. A session can start with a spreadsheet, a customer request, a document, a disconnected system or an idea for a useful application.

- Set up **Codex** with clear project instructions, useful tools and checks.
- Build reusable **agent skills, MCP servers, connectors and plugins**.
- Connect everyday applications, information sources and **APIs**.
- Develop workflows for commerce, documents, **printing systems**, learning and media.
- Build, test and maintain websites, applications and internal tools.

The work below informs what I teach. Training and implementation are scoped to the task, the available interfaces and the learner’s experience.

## How I work

Understand the task, build a useful first version, test what can go wrong and document how to run it. I own the decisions and review the work produced with AI tools.

The handoff matters: people should be able to explain the result, check it and use it again.
