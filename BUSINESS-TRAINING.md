# Build skills around the work you do

Through **Ninobyte**, I help people and teams learn to build, connect and use practical technology. For a small business, that means starting with an everyday task and developing the skills and tools to handle it well.

**[Visit Ninobyte](https://ninobyte.com/)** · [Explore IT training](https://ninobyte.com/training) · [Discuss your training needs](https://ninobyte.com/contact)

## Codex setups and reusable agent skills

Set up a useful workspace, write project instructions, choose tools and practise reviewing changes. Build reusable agent skills that capture a repeatable task, its inputs and the checks that make the result useful.

**Example:** turn a recurring reporting task into a documented workflow that a colleague can run and check.

## MCP servers, connectors, plugins and APIs

Learn to build or adapt a connection between an assistant and a business system. Work through inputs, authentication, permissions, errors and recovery, then package the workflow in the form the chosen tools support.

**Example:** let an assistant find approved information in an internal knowledge source, with clear boundaries on what it can read or change.

This draws on my MCP implementation and API integration work, alongside the developing [Connected Tools & APIs learning path](https://learn.ninobyte.com/learning-paths/connected-tools-apis/).

## Commerce, inventory and business data

Clean a catalogue, check a spreadsheet, prepare invoices or build a report that traces its answers to source records. Learn when an export is enough and when a system connection is worth building.

**Example:** make a stock-review report from an approved export, then evaluate a Clover or other POS connection if it proves useful.

[Ojanaa project](./case-studies/ojanaa.md) · [Proposed inventory pilot](./proposals/clover-inventory-pilot.md)

## Websites, applications and internal tools

Turn a problem into a small working application. Practise forms, validation, data handling, testing and recovery with Codex, then learn how to maintain the result.

**Example:** build a customer-request form that gives clear confirmation and handles an interrupted submission.

[Builders 60 build story](./case-studies/builders60.md)

## Documents and printing workflows

Build reusable document templates, prepare PDFs, check print layouts and connect the steps from source data to a useful output.

**Example:** produce a checked invoice, label or job sheet, then explore delivery to an existing printing system through its supported API, driver or queue. Device integration is scoped and tested against the actual system.

## Learning resources and staff knowledge

Organize information so people can find it, use it and learn from it. Create practical guides, searchable resources, onboarding material and worked examples with clear review steps.

**Example:** turn a repeated staff question into a short guide and an exercise that checks understanding.

[Ninobyte Learning](./case-studies/ninobyte-learning.md) · [Prepnest Library](./case-studies/prepnest-library.md) · [GHSchools](./case-studies/ghschools.md)

## Media, content and everyday operations

Develop repeatable workflows for content preparation, narration, captions, presentations and live delivery. Apply the same approach to handovers, customer replies and routine team documents.

**Example:** prepare a short training demonstration with checked captions and a runbook another person can follow.

[Media, Voice & Live Systems path](https://learn.ninobyte.com/learning-paths/media-voice-live-systems/) · [All learning paths](https://learn.ninobyte.com/learning-paths/)

## What a useful session produces

Bring one task and material you have permission to use. Together, we define the result, build a small version, try realistic failures and leave instructions for repeating it.

These are areas for tailored training and implementation, with the scope agreed around experience, access and supported interfaces. The examples are starting points; each project page records what has actually been built. The free starter is published, while specialist programmes remain in development—check the [learning website](https://learn.ninobyte.com/) for current availability.
