# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability referenced in this portfolio, please report it responsibly.

**Email:** [isaac@nortey.dev](mailto:isaac@nortey.dev)

Include:
- Description of the vulnerability
- Which project is affected
- Steps to reproduce
- Potential impact

I will acknowledge receipt within 48 hours and aim to provide a fix or mitigation plan within 7 days.
